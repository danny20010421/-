# 海賊王 偉大航路｜篇章探索 RPG

參考賽爾號玩法的海賊王對戰遊戲。純前端靜態網站，不需要後端，可直接放上 GitHub Pages。

## 部署到 GitHub Pages

**方法一：自動部署（推薦）**
1. 在 GitHub 建立新的 repository（例如 `op-voyage`），設為 Public。
2. 把這個資料夾所有檔案上傳到 repository 根目錄（包含隱藏的 `.github/` 與 `.nojekyll`）。
   - 網頁上傳：repository 頁面 → Add file → Upload files，把整個資料夾內容拖進去。
   - 或用指令：
     ```
     git init && git add . && git commit -m "first voyage"
     git branch -M main
     git remote add origin https://github.com/你的帳號/op-voyage.git
     git push -u origin main
     ```
3. 到 **Settings → Pages → Build and deployment**，Source 選 **GitHub Actions**。
4. 等 Actions 分頁的 workflow 跑完（約 1 分鐘），網址會是 `https://你的帳號.github.io/op-voyage/`。

**方法二：分支部署**
Settings → Pages → Source 選 **Deploy from a branch**，Branch 選 `main` / `(root)`。

> 網頁上傳時如果看不到 `.github` 資料夾，用方法二即可，效果相同。

## 模式
- 出航後進入模式首頁：**奪寶大冒險**（左右槳交替划船的跑酷，js/runner.js）、**關卡挑戰**（八座島）、**勇者之塔**（120 層，每 10 層 BOSS，js/tower.js）。
- **玩家資料**（js/modes.js）：名稱、8 位數固定 ID、登船時間、稱號（`TITLES` 於 js/data.js）。
- **角色數值**：攻擊力＝傷害倍率×1000；防禦力每 100 點約減傷 1.6%（上限 25%）。

## 玩法
- **登入頁**：循環動畫背景、船上告示（可分類瀏覽、可管理）。
- **入門船員**：新玩家獲得 LV1 的初登場魯夫、索隆、香吉士，全部上陣（陣容最多 3 人），第一位是先鋒（在島上行走的角色）。
- **新手拉霸**：選完先鋒後，可在懸賞處免費拉一次拉霸，召喚一位 LV100 船員，可選擇上陣或先放進角色背包（只有一次）。
- **升級**：打贏敵人、推進劇情、擊敗 BOSS 都會得到經驗與貝里；角色背包可使用經驗書。未上陣的船員分享部分經驗。
- **技能解鎖**：五招分別在 LV1、10、30、40、60 解鎖；技能次數從原設 -3 開始，LV30 +1、LV60 +2，LV100 恢復原設上限。
- **等級階段**：見習海賊 → 超新星（20）→ 七武海級（40）→ 大將級（60）→ 四皇級（80）→ 海賊王級（100），體力、速度、傷害倍率隨等級成長；敵我等級差會影響傷害。
- **取得其他角色**：擊敗篇章 BOSS 有機率讓 BOSS 加入（以 LV20 加入）；懸賞召喚每抽 3% 出現角色。機率與等級都可在管理後台調整。
- **戰鬥**：1–5 選技能、I 道具、L 紀錄；點左下陣容頭像換人（花一回合）；出戰者倒下時免費換下一位，全員倒下才算戰敗。
- **能力階級**：攻擊、防禦每階 ±10%，速度每階 ±5%，上下限 ±6。
- **異常狀態**：冰凍（每回合 -2% 體力、速度下降）、燒傷（每回合 -4%）、虛弱（傷害下降、受傷增加）、破防（受傷 +5%）；疲憊、麻痺、恐懼、固化會讓角色一回合無法使用技能。
- **篇章**：8 座島嶼依漫畫順序解鎖，每章任務組合不同（對話、打聽、前往、收集、限時收集、擊敗、連戰、選擇題、BOSS）。
- **任務類型**：對話、打聽、前往、收集、限時收集、限時路線（依序通過檢查點）、潛入（避開巡邏兵的紅色視野）、護送（NPC 跟著你走）、探測挖掘（跟著探測器溫度找寶物）、擊敗、連戰、選擇題、BOSS。
- **主線「拉夫德魯之路」**：篇章完成後，在該島用探測器找出歷史本文；集齊 5 塊後，從海圖的「寶藏日誌」前往最終之島，挑戰體力不回復的三連戰。
- **難度**：敵人等級隨章節提高；開啟「等級同步」時，陣容太強會讓敵人跟著變強；後三章 BOSS 可復活 2 次。
- **任務指引**：目標光柱與地面光圈、任務 NPC 腳下金色光圈、畫面邊緣方向箭頭與距離、小地圖虛線、任務欄「自動前往」。
- **寶箱**：每座島 3 個，位置第一次登島時決定；全部打開另有獎勵。
- **島嶼差異化**：各章在 `js/data.js` 的 `layout`（出生點、BOSS 擂台、道路折線、海岬陸塊、小兵站位）。
- **懸賞處**：懸賞召喚（寶藏幣）、懸賞任務（每日 4 張，賺貝里）、道具商店（貝里購買，也能兌換寶藏幣）、海軍本部（販賣船員換貝里或經驗，無法反悔）。
- **角色背包**：分為「我的船員」（只列已獲得角色，含等級、能力、技能與升級）、「角色圖鑑」（全部角色，未獲得以剪影顯示）、「訓練營」（最多 3 位，10 分鐘 +400、30 分鐘 +1,100、60 分鐘 +2,000、24 小時 +14,400 經驗；訓練中不能出戰，中止不給經驗；方案在 js/data.js 的 TRAIN_PLANS 調整）。
- **出戰順序**：上方「出戰順序」可拖曳或用箭頭排列陣容；展開「使用經驗道具」可選擇數量並預覽升級結果（經驗書只給選中的角色）。
- **介面（參考賽爾號）**：登島抵達標題；靠近人物時角色旁浮出「對話／挑戰」泡泡；大立繪對話框（NPC 立繪由 3D 模型即時拍攝），「」內的關鍵字標紅；右下角電話蟲（H）提示目前任務；底部功能列（角色／背包／懸賞處／海軍本部／海圖）。
- **戰鬥介面**：遭遇轉場、屬性相剋條（克制 ×1.25／微弱 ×0.8，後台可調整，設為 1 即關閉；相剋表在 js/data.js 的 TYPE_CHART）、「你的回合」提示、奧義圓鈕、自動戰鬥、×1／×2／×3 加速、勝利畫面。
- **音樂音效**：Web Audio 即時合成的原創配樂與音效；右上角 ♪ 可開關。
- **管理後台**：登入頁「管理後台」，可調整戰鬥規則、能力階級幅度、異常狀態數值、角色數值與技能、篇章 BOSS 與難度、劇情對白、召喚機率，並可匯出／匯入設定。

## 自訂內容
| 想改的東西 | 檔案 |
| --- | --- |
| 角色數值、技能 | 管理後台，或 `js/data.js` 的 `CHARACTERS` |
| 篇章劇情、NPC 對話、任務獎勵、BOSS | 管理後台，或 `js/data.js` 的 `CHAPTERS` |
| 技能動畫 | `js/fx.js` 的 `CHOREO` |
| 配樂與音效 | `js/audio.js` |
| 扭蛋道具與機率 | `js/data.js` 的 `ITEMS`、`RARITY` |

| 篇章封面圖 | 換掉 `assets/chapters/*.webp`（檔名不變即可） |
| 3D 場景 | `js/scenes.js` |

## 注意
- 存檔、公告與後台設定都保存在各自瀏覽器的 localStorage，不同裝置不會同步。要讓所有玩家套用同一份設定，請在後台匯出後，把數值改進 `js/data.js`。
- 3D 場景使用自製 WebGL 引擎，不依賴外部 CDN；只有字型從 Google Fonts 載入，連不到時會自動改用系統字型。


## 更新注意事項
- `js/data.js` 開頭的 `DATA_VERSION` 是資料版本。每次修改角色或劇情資料後加一：
  - 玩家瀏覽器裡的舊版後台設定會自動停用並備份，避免舊劇情蓋掉新內容。
  - 所有程式、樣式與圖片網址都會帶上新的版本參數，瀏覽器會重新下載，不會卡在舊檔。
- `index.html` 裡的 `?v=15` 也要同步改成新的版本號。
